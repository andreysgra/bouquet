# Проект «Цветочный магазин» от [HTML Academy](https://htmlacademy.ru/)

«Цветочный магазин» — сайт магазина букетов. Пользователь может просматривать все доступные букеты или отфильтрованные по заданным параметрам. Понравившиеся букеты пользователь может добавить в отложенное.

Программирование: [Андрей Грачев](https://github.com/andreysgra/)

[Техническое задание](Specification.md)

## Используемый стек

JavaScript (ES6). Проект разработан в соответствии с архитектурным паттерном MVP.

## Как использовать

`npm install` – установка зависимостей.

`npm start` – сборка проекта в режиме разработки и запуск локального сервера.

`npm run build` – финальная сборка проекта.

`npm run lint` – запуск теста на соответствие правилам ESLint.
